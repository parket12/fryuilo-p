# Система аутентификации

## Описание

Реализована базовая система регистрации и авторизации пользователей для Spring Boot приложения.

## Функциональность

### Регистрация пользователя
- Форма регистрации с проверкой обязательных полей
- Валидация данных:
  - Имя и фамилия (2-50 символов)
  - Email (уникальный, корректный формат)
  - Логин (3-30 символов, уникальный)
  - Пароль (минимум 6 символов)
  - Телефон (корректный формат)
  - Дата рождения (обязательна)
- Хеширование паролей с помощью BCrypt
- Проверка уникальности email, логина и телефона

### Авторизация пользователя
- Форма входа с логином и паролем
- Проверка учетных данных
- Создание пользовательской сессии
- Перенаправление на главную страницу после успешного входа

### Управление сессией
- Отображение информации о текущем пользователе
- Кнопка выхода из системы
- Автоматическое перенаправление неавторизованных пользователей

## Структура файлов

### Модель
- `User.java` - обновлена с полями `username` и `password`

### Контроллеры
- `AuthController.java` - обработка регистрации, входа и выхода
- `HomeController.java` - главная страница с проверкой авторизации

### Сервисы
- `AuthService.java` - бизнес-логика аутентификации
- `UserService.java` - существующий сервис для работы с пользователями

### Репозиторий
- `UserRepository.java` - добавлены методы для работы с логином

### Конфигурация
- `SecurityConfig.java` - настройка Spring Security

### Шаблоны
- `auth/register.html` - форма регистрации
- `auth/login.html` - форма входа
- `layout.html` - обновлен с поддержкой аутентификации
- `index.html` - обновлена главная страница

## Использование

### Предустановленные пользователи
При запуске приложения автоматически создаются два пользователя:

1. **admin / admin** - администратор
   - Имя: Admin Administrator
   - Email: admin@example.com
   - Телефон: 79990000001
   - После входа перенаправляется на главную страницу для редактирования таблиц

2. **url / url** - обычный пользователь
   - Имя: Url User
   - Email: url@example.com
   - Телефон: 79990000002
   - После входа перенаправляется на страницу "Добро пожаловать"

### Регистрация
1. Перейдите на `/auth/register`
2. Заполните все обязательные поля
3. Нажмите "Зарегистрироваться"
4. При успешной регистрации будете перенаправлены на страницу входа

### Вход в систему
1. Перейдите на `/auth/login`
2. Введите логин и пароль (например, admin/admin или url/url)
3. Нажмите "Войти"
4. При успешном входе будете перенаправлены:
   - Пользователь `url` → страница "Добро пожаловать" (`/welcome`)
   - Остальные пользователи → главная страница (`/`)

### Выход
- Нажмите кнопку "Выход" в навигации или на главной странице

## Безопасность

- Пароли хешируются с помощью BCrypt
- Проверка уникальности учетных данных
- Валидация входных данных
- Управление сессиями пользователей

## Зависимости

Добавлена зависимость Spring Security в `pom.xml`:
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security</artifactId>
</dependency>
```

## Запуск приложения

1. Убедитесь, что все зависимости установлены
2. Запустите приложение: `mvn spring-boot:run`
3. Откройте браузер и перейдите на `http://localhost:8080`
4. Для доступа к системе сначала зарегистрируйтесь или войдите
